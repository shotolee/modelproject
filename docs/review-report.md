## 问题清单

使用稳定问题编号如 R-01。每项包含：

- 类型：实现缺陷 / 必需证据缺口 / 可选改进。
- 等级：Critical / Major / Minor / Suggestion；建议是否阻塞及理由。
- 位置、触发条件、实际与预期行为，或具体缺失的强制证据。
- 产品、设计或计划的验收依据；新实证安全/正确性缺陷另注明，不凭偏好扩大验收。
- 建议的最小修复及复核方法。

尚未评审，不代表没有问题。无发现也注明范围和限制。Minor/Suggestion 默认非阻塞，主负责人明确处置；实证重大缺陷和未闭强制证据不能通过降级隐藏。

## 报告交付核验

reviewer 写完后读回，确认当前结论、范围和实施 SHA，再仅提交报告；提交后用 Git 读取该报告提交核对内容，在交接消息给出报告 SHA。主负责人读取同一提交再验收。无法提交或读回不一致则交付 Pending，不猜覆盖者，不声称审查完成。不在报告内预测自身哈希。
